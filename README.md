# AI Reference Studio 公開素材

原始索引位元組保留於 source/，原始 PNG 保留於 originals/，Depth 依角度保留於 variants/depth/。320px 縮圖與 1024px 預覽為衍生 WebP。

index.json 提供索引及關聯，integrity.json 與 SHA256SUMS.sha256 提供整批 SHA-256 核對。姿勢使用原站唯一 key 作為 id，原站顯示 ID 保留在 sourceId。同一角度的原始姿勢 PNG 也是原站線稿。
